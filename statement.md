# Project Statement

## Problem Statement

Students often spend money on food, transportation, study materials,
and other daily activities without maintaining a simple record of
their expenses. The Student Expense Tracker provides a simple
command-line solution for recording and reviewing daily expenses.

## Scope

The project focuses on adding, viewing, deleting, and analyzing
personal expenses. Expense data is stored in a JSON file so that
records remain available after the program is closed.

## Target Users

The primary target users are students who want a simple and
lightweight application to track their daily expenses.

## High-Level Features

- Add expenses
- View all expenses
- Delete expenses
- Calculate total spending
- Category-wise expense summary
- JSON-based persistent storage
- Input validation
- Automated testing
